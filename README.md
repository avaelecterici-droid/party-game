# 🎉 باشگاه ذهن گروهی — راهنمای پوشه

```
party-game/
├─ index.html              ← بازی (این را باز کنید)
├─ assets.js               ← فهرست عکس‌ها و صداها (خودکار ساخته می‌شود)
├─ questions.js            ← سؤال‌های پیش‌فرض شما (خودکار ساخته می‌شود)
├─ questions-template.csv  ← قالب نمونه‌ی سؤال‌ها
├─ images/                 ← عکس مکان‌ها و آدم‌ها (نام فایل = جواب)
├─ sounds/                 ← صداها و آهنگ‌ها (نام فایل = جواب)
└─ tools/make_assets.py    ← ساخت assets.js و questions.js
```

## ۱) اجرا
فایل `index.html` را در مرورگر (Chrome/Safari) باز کنید.

## ۲) عکس‌ها (مرحله‌ی «این کجاست؟ یا کیه؟»)
- عکس را در پوشه‌ی `images` بگذارید؛ **نام فایل همان جواب است**.
  مثال: `برج میلاد.jpg` ← جواب «برج میلاد».
- پیشوند شماره مجاز است و حذف می‌شود: `01-دایی علی.png` ← «دایی علی».
- پسوندهای مجاز: jpg, jpeg, png, webp, gif, svg
- عکس‌های نمونه‌ی فعلی را می‌توانید پاک یا عوض کنید.

## ۳) صداها (مرحله‌ی «صدای کی بود؟»)
- فایل صوتی را در پوشه‌ی `sounds` بگذارید؛ **نام فایل همان جواب است**.
  مثال: `خواننده‌ی مورد علاقه.mp3` یا `صدای دایی علی.m4a`.
- پسوندهای مجاز: mp3, wav, ogg, m4a, aac, webm
- ۴ صدای نمونه (زنگ در، آژیر، زنگ تلفن، سوت داور) فقط برای تست است؛ صداهای خودتان را جایگزین کنید.
- نکته: کلیپ‌های کوتاه (۵ تا ۱۵ ثانیه) بهتر است.

## ۴) سؤال‌ها
- `questions-template.csv` را در Excel یا Google Sheets باز و پر کنید و با نام **`questions.csv`** (فرمت CSV UTF-8) کنار `index.html` بگذارید.
- گزینه‌ی درست همیشه ستون سوم است؛ بازی خودش جای گزینه‌ها را قاطی می‌کند.
- هر دسته که سؤال داشته باشد، جای سؤال‌های پیش‌فرض همان دسته را می‌گیرد.

## ۵) به‌روزرسانی فهرست (مهم)
بعد از هر تغییر در `images` ،`sounds` یا `questions.csv` این دستور را اجرا کنید (نیاز به Python دارد):

```
python tools/make_assets.py
```
اگر Python ندارید، فایل `assets.js` را با ویرایشگر متن باز کنید و ردیف‌ها را دستی اضافه یا حذف کنید (هر ردیف: `file` مسیر فایل و `name` جواب).

## ۶) فرستادن برای بقیه
- **ساده‌ترین راه:** کل پوشه را ZIP کنید و بفرستید؛ گیرنده زیپ را باز می‌کند و `index.html` را اجرا می‌کند. عکس‌ها و صداها همراه پوشه‌اند و دوباره جست‌وجو نمی‌خواهند.
- **برای گوشی:** باز کردن فایل از داخل ZIP روی گوشی معمولاً مشکل دارد. بهتر است پوشه را روی یک سایت رایگان (مثل Netlify Drop یا GitHub Pages) آپلود کنید و **لینکش** را بفرستید؛ همه با یک لینک بازی می‌کنند.
- عکس/صدا/سؤالی که هر نفر داخل خود بازی (صفحه‌ی اول) اضافه کند، فقط روی دستگاه خودش ذخیره می‌شود و جایگزین موارد پوشه می‌شود.

## ۷) نمایش روی تلویزیون
- دکمه‌ی «📺 حالت تلویزیون» (پایین-چپ صفحه) بازی را تمام‌صفحه، بزرگ‌تر و بدون خاموش‌شدن صفحه می‌کند.
- اگر گوشی را با «انعکاس صفحه» (Screen Mirroring) وصل می‌کنید، گوشی را **افقی** بگیرید و قفل چرخش را خاموش کنید؛ وگرنه تلویزیون یک نوار باریک نشان می‌دهد.
- بهترین کیفیت: از لپ‌تاپ یا Chrome گوشی گزینه‌ی Cast ← «Cast tab» استفاده کنید.

## ۸) ذخیره‌ی مستقیم عکس و صدا داخل پوشه (سرور محلی)
مرورگر به‌تنهایی اجازه‌ی نوشتن داخل پوشه‌ی کامپیوتر را ندارد؛ برای همین یک سرور کوچک گذاشته‌ام:
1. روی کامپیوتر/لپ‌تاپ **Python 3** نصب باشد.
2. `start-server-windows.bat` (ویندوز) یا `start-server-mac-linux.command` (مک/لینوکس) را دوبار کلیک کنید.
3. آدرسی که چاپ می‌شود را در مرورگر باز کنید: `http://localhost:8000` (روی گوشی/تلویزیون در همان Wi-Fi: آدرس IP که نمایش داده می‌شود).
4. حالا در صفحه‌ی اول، «بانک عکس» و «بانک صدا» مستقیم در پوشه‌ی `images` و `sounds` ذخیره می‌کنند (نوار سبز 🟢 بالای صفحه). لازم نیست `make_assets.py` را اجرا کنید؛ فهرست خودکار به‌روز می‌شود. دکمه‌ی ✕ هم فایل را از پوشه پاک می‌کند.
5. پوشه را ZIP کنید و بفرستید؛ عکس‌ها و صداهای اضافه‌شده همراهش هست.

نکته‌ها:
- فقط روی شبکه‌ی خانگی خودتان اجرا کنید.
- ضبط مستقیم با میکروفون فقط روی `localhost` (همان کامپیوتر) کار می‌کند؛ روی گوشی از طریق IP مرورگر اجازه‌ی میکروفون نمی‌دهد. در گوشی فایل صوتی انتخاب کنید.
- روی گوشی تنها (بدون کامپیوتر) نوشتن داخل پوشه ممکن نیست؛ آنجا فایل‌ها فقط روی همان گوشی ذخیره می‌شوند.

## ۹) فرمت فایل‌ها
**عکس‌ها:** JPG (بهترین)، PNG، WebP، GIF، SVG
- عکس افقی، عرض حدود ۱۰۰۰ تا ۱۶۰۰ پیکسل، حجم زیر ۱ مگابایت.
- فرمت HEIC آیفون را به JPG تبدیل کنید (تنظیمات دوربین ← Formats ← Most Compatible).

**صداها:** MP3 (بهترین و سازگار با همه)، M4A/AAC، WAV، OGG، WebM
- کلیپ کوتاه ۵ تا ۱۵ ثانیه، ترجیحاً MP3 با کیفیت ۱۲۸kbps (حدود ۲۰۰ تا ۵۰۰ کیلوبایت).
- WAV خیلی حجیم است. OGG و WebM روی بعضی آیفون‌ها پخش نمی‌شوند؛ برای گوشی‌های مختلف MP3 یا M4A بهتر است.

## ۱۰) اگر عکسی که گذاشتم دیده نمی‌شود
مرورگر وقتی `index.html` را مستقیم (دوبل‌کلیک) باز می‌کنید، اجازه‌ی دیدن محتوای پوشه‌ها را ندارد و فقط فهرستِ `assets.js` را می‌خواند. سه راه:
1. **پیشنهاد اصلی:** `start-server-windows.bat` (یا `start-server-mac-linux.command`) را اجرا کنید. مرورگر خودش باز می‌شود و هر بار که صفحه را باز/رفرش کنید، پوشه‌های `images` و `sounds` دوباره خوانده می‌شوند؛ نیازی به هیچ کار دیگر نیست.
2. در Chrome یا Edge کامپیوتر، همان `index.html` را باز کنید و در صفحه‌ی اول دکمه‌ی «📂 خواندن پوشه‌ی پروژه» را بزنید و پوشه‌ی `party-game` را انتخاب کنید (هر بار که صفحه را باز می‌کنید باید دوباره بزنید).
3. دستور `python tools/make_assets.py` را اجرا کنید تا `assets.js` به‌روز شود.

## ۱۱) استفاده فقط با گوشی (بدون Python و سرور)
**بهترین راه: یک‌بار آنلاین کردن پوشه (رایگان) و بعد استفاده از لینک**
1. (یک‌بار، حتی با کمک یک دوست/لپ‌تاپ) در github.com یک حساب و یک مخزن (Repository) **عمومی** بسازید و کل محتوای پوشه را در آن آپلود کنید.
2. در Settings ← Pages، گزینه‌ی «Deploy from a branch» و شاخه‌ی main را انتخاب کنید. بعد از حدود یک دقیقه آدرس `https://نام‌شما.github.io/نام-مخزن/` ساخته می‌شود.
3. این لینک را برای همه بفرستید؛ همه با گوشی خودشان با یک لینک بازی می‌کنند و عکس‌ها/صداهای پیش‌فرض خودکار می‌آیند.
4. بعداً هر عکس/صدا را فقط با گوشی (مرورگر یا اپ GitHub) در پوشه‌ی `images` یا `sounds` مخزن آپلود کنید؛ بازی خودش فهرست پوشه‌ها را از GitHub می‌خواند و لازم نیست `assets.js` را عوض کنید (حدود ۱ دقیقه تأخیر برای انتشار).
5. برای سؤال‌ها هم فایل `questions.csv` را در مخزن آپلود کنید؛ بازی خودکار می‌خواندش.
(محدودیت: GitHub برای هر شبکه حدود ۶۰ بار خواندن فهرست در ساعت اجازه می‌دهد؛ اگر پر شد، بازی از `assets.js` استفاده می‌کند.)

**راه بدون آنلاین‌کردن:** `index.html` را در گوشی (اندروید: از برنامه‌ی Files با Chrome) باز کنید و در صفحه‌ی اول عکس/صدا را از گالری یا میکروفون اضافه کنید. این‌ها فقط روی همان گوشی ذخیره می‌شوند.
